# Portfolio Strategy & Execution Rules

## Core Stack Rules
- **Framework**: HTML, JavaScript (Vanilla). If a framework is later requested, use Next.js or Vite.
- **Styling constraints**: Vanilla CSS. Avoid Tailwind CSS unless explicitly requested by the user.
- **Optimization rules**: High-performance rendering for 2D motion graphics, VFX videos, and explainer videos. Lazy load videos and optimize assets.

## Design Token Boundaries
**Visual Vibe**: Playful, vibrant, energetic, and highly creative.
- **Typography**: Primary: `Outfit` (bold, geometric, playful). Secondary: `Inter` (clean readability for case studies).
- **Colors**:
  - Background: Deep Dark Purple `#0B0914` (makes vibrant colors pop).
  - Primary Accent: Neon Pink `#FF2A6D`
  - Secondary Accent: Electric Cyan `#05D9E8`
  - Tertiary Accent: Bright Yellow `#FFC600`
  - Text: Off-white `#F1F1F1`
- **Spacing**: Base-4 spacing system (4px, 8px, 16px, 24px, 32px, 48px, 64px, 96px, 128px, etc.).
- **Radius**: Soft, playful corners. `border-radius: 16px` for cards, `border-radius: 9999px` for pill buttons.
- **Animations**: Micro-animations on hover (scale up, color shift). 

## Psychological Storytelling Structure
1. **The Hook (Hero Section)**:
   - *Psychological Concept*: Zeigarnik Effect (Start with a bang, leave them wanting to see the full projects).
   - *Execution*: A massive, vibrant, auto-playing showreel that immediately demonstrates 2D motion and VFX capabilities. Bold typography.
2. **The "Aha!" Moment (Value Prop / Specialization)**:
   - *Psychological Concept*: Cognitive Ease (Make the offering instantly clear to busy agency directors).
   - *Execution*: Clear, snappy breakdown of services: 2D Motion Graphics, Explainer Videos, Visual Effects.
3. **Show, Don't Tell (Selected Works)**:
   - *Psychological Concept*: Dual Coding Theory (Combine stunning visuals with brief, impactful context).
   - *Execution*: Interactive grid of top projects. Hovering over a project plays a short video loop. Clicking opens a case study.
4. **The Halo Effect (Social Proof)**:
   - *Psychological Concept*: Authority & Trust.
   - *Execution*: Logos of agencies, brands, or studios worked with.
5. **Commitment & Consistency (Call to Action)**:
   - *Psychological Concept*: Fogg Behavior Model (High motivation + high ability + trigger).
   - *Execution*: A highly interactive, playful contact section. "Got a brief? Let's make it move." 

## Code Quality Standards
- **Accessibility**: Semantic HTML5. `aria-labels` on all interactive elements. Sufficient color contrast.
- **Semantics**: Use standard elements like `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- **Aesthetics First**: The UI must look premium and dynamic. Incorporate hover effects, smooth transitions, and rich aesthetics to avoid a generic look.
